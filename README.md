# Budget & Expense Tracker

A console-based Budget and Expense Tracker built using C++.

## Features

- Add Expense
- Show All Expenses
- Edit Expense
- Delete Expense
- Search by Category
- Search by Description
- Calculate Total
- Expense Count
- Average Expense
- Category Summary
- Date Summary
- Daily Summary
- Monthly Summary
- Highest Expense
- Minimum Expense
- Set Monthly Budget
- Remaining Budget
- File Save and Load
- Input Validation

## Concepts Used

- C++
- OOP
- Classes and Objects
- Encapsulation
- Constructors
- Getters and Setters
- Vector
- Unordered Map
- File Handling
- Input Validation
